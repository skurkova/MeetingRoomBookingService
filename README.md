# 🏛️ Meeting Room Booking Service

Веб-сервис для автоматизации бронирования переговорных комнат в коворкинге.
---

## 🎯 Возможности

### Для сотрудников 👤:
- 🔍 Просмотр доступности всех комнат на конкретную дату
- ✅ Создание бронирований на свободные временные слоты
- ❌ Отмена **только своих** бронирований
- 🔒 Доступ к чужим броням запрещён

### Для администраторов 👑:
- Все возможности сотрудника
- ❌️ Отмена **любых** бронирований (включая чужие)
- 🔍 Просмотр всех бронирований в системе

## 🚀 Установка и запуск

### Шаг 1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/skurkova/MeetingRoomBookingService.git
cd MeetingRoomBookingService
```


### Шаг 2. **Создайте файл `.env`**
```bash
cp .env.example .env
```

### Шаг 3. **Запустите сервисы через Docker Compose**
```bash
docker compose up --build
```
или в фоновом режиме
```bash
docker compose up -d --build
```

### Шаг 4. **Откройте браузер:**
- API документация: http://localhost:8000/docs
- Альтернативная документация: http://localhost:8000/redoc

В документации можно:
- Просматривать все доступные эндпоинты
- Тестировать API прямо из браузера
- Видеть схемы запросов и ответов
- Авторизоваться для тестирования защищённых эндпоинтов

### Шаг 5. **Остановите сервисы при необходимости:**
```bash
docker compose down -v
```

## 📡 REST API

* **URL:** http://localhost:8000
* **Интерактивная документация:** http://localhost:8000/docs  
* **Аутентификация:** JWT Bearer Token (заголовок `Authorization: Bearer <token>`)

##  🗓️ Сводная таблица эндпоинтов

| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| `POST` | `/auth/login` | Получение JWT-токена | 🌐 Публичный |
| `GET` | `/rooms/` | Список всех комнат и доступность слотов | 🌐 Публичный |
| `GET` | `/rooms/{id}` | Информация о конкретной комнате | 🌐 Публичный |
| `GET` | `/bookings/` | Список бронирований | 🔒 Только авторизованные |
| `POST` | `/bookings/` | Создание нового бронирования | 🔒 Только авторизованные |
| `GET` | `/bookings/{id}` | Детали конкретного бронирования |  Только авторизованные |
| `DELETE` | `/bookings/{id}` | Отмена (удаление) бронирования | 🔒 Только авторизованные |

## 🔐 Аутентификация
**🌐 Публичный доступ**

### `POST /auth/login`
Получение JWT-токена по логину и паролю.
* **Тело запроса (form-data):** `username` и `password`
* **Ответ (200 OK):** `{"access_token": "...", "token_type": "bearer"}`
* **Ответ (401 Unauthorized):** `{"detail": "Incorrect username or password"}`

## 🏢 Комнаты 
**🌐 Публичный доступ**

### `GET /rooms/`
Возвращает список всех комнат с их временными слотами и статусом доступности `is_available`.
* **Query-параметры:** `target_date` (YYYY-MM-DD). По умолчанию — текущая дата.
* **Ответ (200 OK):** Массив объектов комнат со вложенными слотами.

### `GET /rooms/{id}`
Возвращает детальную информацию о конкретной комнате и её слотах.
* **Ответ (200 OK):** Объект комнаты.
* **Ответ (404 Not Found):** `{"detail": "Room not found"}`

## 📅 Бронирования 
**🔒 Только для авторизованных**

### `GET /bookings/`
Получение списка бронирований.
* **Права доступа:**
  * 👤 **Сотрудник:** видит только свои бронирования.
  * 👑 **Администратор:** видит все бронирования в системе.
* **Ответ (200 OK):** Массив объектов бронирования.

### `POST /bookings/`
Создание бронирования на свободный слот.
* **Тело запроса (JSON):** `{"room_slot_id": 1, "booking_date": "2026-07-25"}`
* **Ответ (201 Created):** Объект созданного бронирования.
* **Ответ (409 Conflict):** `{"detail": "Room is already for this datetime booking"}`

### `GET /bookings/{id}`
Получение деталей конкретного бронирования.
* **Права доступа:**
  * 👤 **Сотрудник:** может просмотреть только своё бронирование.
  * 👑 **Администратор:** может просмотреть любое бронирование.
* **Ответ (200 OK):** Объект бронирования.
* **Ответ (403 Forbidden):** `{"detail": "FORBIDDEN for this user"}`
* **Ответ (404 Not Found):** `{"detail": "Booking not found"}`

### `DELETE /bookings/{id}`
Отмена бронирования.
* **Права доступа:**
  * 👤 **Сотрудник:** может отменить только своё бронирование.
  * 👑 **Администратор:** может отменить любое бронирование.
* **Ответ (204 No Content):** Успешное удаление (тело ответа пустое).
* **Ответ (403 Forbidden):** `{"detail": "FORBIDDEN for this user"}` 
* **Ответ (404 Not Found):** `{"detail": "Booking not found"}`

### 💡 Пример использования API

**1. Получаем токен (скопируй значение `access_token` из ответа):**
```bash
curl -X POST "http://localhost:8000/auth/login" \
  -d "username=admin&password=admin123"
```

**2. Смотрим доступность комнат (токен НЕ требуется, эндпоинт публичный):**
```bash
curl -X GET "http://localhost:8000/rooms/?target_date=2026-07-25"
```

**3. Создаем бронирование (требуется авторизация, вставь полученный `access_token` вместо <YOUR_TOKEN>):**
```bash
curl -X POST "http://localhost:8000/bookings/" \
  -H "Authorization: Bearer <YOUR_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"room_slot_id": 1, "booking_date": "2026-07-25"}'
```

**5. Отменяем бронирование (с токеном):**
```bash
curl -X DELETE "http://localhost:8000/bookings/1" \
  -H "Authorization: Bearer <YOUR_TOKEN>"
```
